# Device mounting clips

3MF models for the 45-degree orbital-shaker setup in the research article under
submission. Model coordinates and dimensions are in millimetres.

| Device | Model | Preview |
|---|---|---|
| AX3 | [ax3.3mf](ax3.3mf) | <img src="previews/ax3.png" alt="AX3 mounting clip" width="140"> |
| GENEActiv 1.2 | [geneactiv.3mf](geneactiv.3mf) | <img src="previews/geneactiv.png" alt="GENEActiv mounting clip" width="140"> |
| ActiGraph LEAP | [leap.3mf](leap.3mf) | <img src="previews/leap.png" alt="LEAP mounting clip" width="140"> |
| ActiGraph wGT3X-BT | [wgt3x-bt.3mf](wgt3x-bt.3mf) | <img src="previews/wgt3x-bt.png" alt="wGT3X-BT mounting clip" width="140"> |
| ActiGraph GT9X Link | [gt9x-link.3mf](gt9x-link.3mf) | <img src="previews/gt9x-link.png" alt="GT9X Link mounting clip" width="140"> |
| SENS motion | [sens-motion.3mf](sens-motion.3mf) | <img src="previews/sens-motion.png" alt="SENS motion mounting clip" width="140"> |

[dimensions.csv](dimensions.csv) records transformed build-envelope width (X),
depth (Y) and height (Z), rounded to 0.1 mm, and model SHA-256 checksums.
Dimensions describe model geometry, not printed-part tolerances. Previews are
embedded 3MF thumbnails. Printer, material and slicer settings are unspecified.
